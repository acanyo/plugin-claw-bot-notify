# 界面截图

2026-11-17 从专用 Halo 2.27.0 测试站的 Codex 内置浏览器获取。图片宽 1440 像素，按内容裁切后转换为 WebP，没有替换页面数据。

- `connection.webp`：微信连接、已脱敏身份和智能助手运行状态。
- `commands.webp`：使用“处理成功”筛选后的指令记录，每页 10 条。
- `messages.webp`：消息发送记录，每页 10 条；“接口已接收”是上游接收结果。

截图未展开访问令牌或连接设置，未展示私人对话正文。更新截图时继续使用专用测试站和已脱敏界面，不使用真实扫码二维码、PAT、Bot token 或未脱敏微信账号。演示站与 QQ 群二维码沿用用户提供的 Joe Next 项目说明。
